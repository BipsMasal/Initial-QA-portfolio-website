I’m a junior QA engineer who enjoys understanding how a product can fail — then turning those failure paths into clear, reproducible tests.

My current focus combines hands-on manual testing with API testing and Playwright automation. I like testing from the user's perspective while also looking underneath the UI to validate requests, responses, data, permissions and edge cases.
