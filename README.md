# Premium QA Engineer Portfolio

Static portfolio website designed for GitHub Pages.

## Files

- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and reveal animations
- `assets/` — add your profile photo/resume here

## Before publishing

Search `index.html` for:
- `Bipin Masal`
- `your.email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- project `href="#"`

Replace those with your real information and project URLs.

## GitHub Pages

1. Create a GitHub repository, e.g. `qa-portfolio`.
2. Upload all files while keeping the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/qa-portfolio/`
